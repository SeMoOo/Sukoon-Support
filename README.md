# Sukoon Support · دعم سكون

Official public support and feedback repository for **Sukoon**, maintained by **Sukoon Team / فريق سكون**.

Sukoon supports prayer times, Qibla, the Quran, Athkar, widgets and Apple Watch.

- [Official support website](https://semooo.github.io/Sukoon-Support/)
- [Privacy policy (English / العربية)](https://semooo.github.io/Sukoon-Support/privacy.html)
- [Report a bug](https://github.com/SeMoOo/Sukoon-Support/issues/new?template=bug_report.md)
- [Request a feature](https://github.com/SeMoOo/Sukoon-Support/issues/new?template=feature_request.md)

Issues are public; do not post personal worship records, precise home coordinates, phone numbers, or other sensitive data.
